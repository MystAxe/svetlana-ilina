- Накопленные изменения отправляются в существующий GitHub-репозиторий; сайт публикует настроенный workflow GitHub Pages. Привязка Sites не меняется.

1. Перед внешней публикацией отдельно подтвердить допустимый объём использования истории и материалов Веры с ней и представителем. Повторно запрашивать уже полученные файлы не нужно.
