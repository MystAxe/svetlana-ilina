# Расчёт результатов теста

## Задача

Тест не ставит диагноз. Он сопоставляет ответы с пятью жизненными сценариями и показывает одно ведущее направление. Если второе направление почти так же выражено, оно выводится как сопутствующее.

| Ключ | Публичный смысл | История |
|---|---|---|
| `recovery` | энергия и восстановление | Полина |
| `cravings` | тяга и ритм питания | Даша |
| `consistency` | цикл «начать — бросить — начать снова» | Света |
| `self-image` | отношение к себе и возвращение ощущения «это снова я» | Оксана |
| `body-shape` | форма, сила и композиция тела | Вера |

## Почему у каждого вопроса один ответ

Вопросы с множественным выбором были заменены на формулировку «выберите наиболее заметный/частый вариант». Иначе пользователь, отметивший много пунктов, получал бы больше баллов сразу во всех сценариях, а результат зависел бы от стиля заполнения анкеты.

## Баллы

Каждый вариант добавляет от 0 до 3 баллов одному или двум сценариям:

- `3` — прямой сильный сигнал;
- `2` — заметный сигнал;
- `1` — сопутствующий контекст;
- `0` — вариант не влияет на сценарий.

Прямые вопросы о текущей боли, повторяющемся поведении и желаемом результате получают больший вес. Вопрос о проверке здоровья влияет только на `recovery` и не используется для медицинских выводов.

## Нормализация

У сценариев разное число релевантных вариантов, поэтому сырые суммы нельзя честно сравнивать напрямую. Для каждого сценария рассчитывается его теоретический максимум: сумма самого большого доступного балла по каждому вопросу.

```text
нормализованный балл = набранные баллы / теоретический максимум × 100
```

Проценты нужны только алгоритму и не показываются посетителю: такая точность выглядела бы как медицинская оценка, которой тест не является.

## Ведущий результат

Сценарии сортируются по нормализованному баллу, затем по сырой сумме. Ведущим становится первый сценарий, подтверждённый минимум двумя разными ответами. При полном равенстве используется стабильный порядок: тяга → восстановление → устойчивость → отношение к себе → форма тела.

## Сопутствующий результат

Второй сценарий показывается только когда одновременно выполнены три условия:

1. он подтверждён минимум двумя ответами;
2. его нормализованный балл не ниже 45;
3. он отстаёт от ведущего не больше чем на 15 пунктов.

Это позволяет отражать смешанную ситуацию, но не превращает результат в длинный список из всех возможных проблем.

## Приватность

Расчёт выполняется в браузере. Ответы не отправляются, не сохраняются в `localStorage`/`sessionStorage` и исчезают после закрытия или обновления страницы. Контакт перед результатом не запрашивается.
