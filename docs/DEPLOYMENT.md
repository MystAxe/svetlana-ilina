# Публикация без WordPress

## Универсальные настройки хостинга

Для Netlify, Cloudflare Pages, Render Static Sites и других Node-based static hosts:

| Параметр | Значение |
|---|---|
| Node.js | 22.12+ или 24+ |
| Install command | `npm ci` |
| Build command | `npm run build` |
| Publish directory | `dist/client` |

Сервер PHP и база данных не нужны. Каждый маршрут уже имеет физический `index.html`, поэтому специальный SPA rewrite не требуется.

## Ручная загрузка

```bash
npm ci
npm run build
```

После успешной проверки нужно загрузить содержимое `dist/client` в корневую директорию сайта на хостинге.

Важно загружать именно содержимое папки, чтобы корневой `index.html`, `assets`, `media` и вложенные маршруты находились на одном уровне.

## Доступные варианты

- `npm run build` — основной независимый статический релиз.
- `npm run build:github-pages` — релиз в `/svetlana-ilina/`.
- `npm run build:sites` — пакет для Sites.
- `npm run build:wordpress` — необязательное обновление локальной WordPress-темы.

## Что не зависит от хостинга

Навигация, истории, фильтры, тест и видео работают полностью на frontend. Текущая форма и отправка результатов теста не имеют сетевого backend: смена хостинга сама по себе не добавит прием заявок. Перед публичным запуском формы потребуется отдельно подключить API или сервис отправки.
