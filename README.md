# Светлана Ильина — браузерный прототип

Многостраничный сайт на Vite и TypeScript: главная, «Формула тела», тест, блог и «Истории перемен». Контент хранится в TypeScript, сборка полностью статическая. WordPress не нужен для работы frontend; отдельный скрипт может скопировать сборку в подготовленную локальную тему.

## Итерация 28–29 августа 2026

Прежний книжный стиль заменён фотографической подачей по первому референсу пользователя: крупный портрет, Manrope, спокойные нейтральные поверхности, округлые элементы и красный акцент. Обновлены главная, услуга, архив, существующие истории и общие шаблоны остальных страниц.

Добавлены истории Даши и Веры. У Даши — четыре коротких видео, русские автосубтитры, фотографии прежнего и изменившегося рациона, выбранные значения из анализов без личных реквизитов. У Веры — фото в начале работы, два видео с сохранённым закрытием лица и выбранные показатели. Имя и возраст не выводятся на первом экране. Для Hero выбран переданный пользователем красный вариант; качественный чёрный оригинал `IMG_3483.JPG` сохранён в трёх размерах WebP для возможного возврата.

Заявка открывается в общем плавном попапе без смены страницы; форма на странице услуги сохранена. FAQ и мобильное меню анимируются в обе стороны. У историй выровнен отступ между завершающим акцентным блоком и футером.

Подробности, ограничения обработки hero и карта материалов: [редизайн 28 августа](docs/REDESIGN_2026-08-28.md). Эта итерация заменяет прежние визуальные правила из исторических документов.

## Запуск и сборка

Требуется Node.js 22.12+ или 24+.

```bash
npm.cmd install
npm.cmd run dev
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```

В PowerShell используется `npm.cmd`; в других shell — обычный `npm`. Готовый сайт находится в `dist/client`.

`build` проверяет TypeScript, собирает все 22 маршрута, проверяет файлы, метаданные ссылок и таймкоды WebVTT. Варианты сборки и настройка адреса для Open Graph описаны в [руководстве по публикации](docs/DEPLOYMENT.md).

## Маршруты

- `/` — фотографическая главная.
- `/formula-tela/` — экспертный разбор «Формула тела».
- `/test/` — интерактивный тест на демонстрационных данных.
- `/istorii-peremen/` — шесть историй и фильтры по ситуации.
- `/istorii-peremen/dasha/` — питание, энергия и форма тела.
- `/istorii-peremen/vera/` — история о форме тела с фото и видео, где лицо скрыто в самих файлах.
- `/istorii-peremen/polina/`, `sveta/`, `vika/`, `oksana/` — существующие истории с собственными материалами.
- `/nastavnichestvo/`, `/o-svetlane/`, `/contacts/` — самостоятельные страницы.
- `/blog/` и три статьи — демонстрационные материалы.
- `/thank-you/` — состояние после будущей отправки формы.
- `/privacy-policy/`, `/personal-data-consent/`, `/offer/`, `/requisites/` — юридические черновики.

Реестр маршрутов: `scripts/site-entries.mjs`.

## Визуальная система

- Основной фон `#F7F6F2`, мягкая поверхность `#EEEEE8`, текст `#252623`.
- Акцент `#C1121F`, мягкий красный фон `#F5E9E5`.
- Локальный variable Manrope используется для всех текстовых ролей. Source Serif больше не используется в дизайне; прежний файл и лицензия сохранены для совместимости сборочного адаптера.
- `src/styles/app.css` содержит базовые токены, доступность и существующие utility-правила; `src/styles/redesign.css` — композиции новой итерации.
- `HomeHero` использует красное боди со светлым креслом в широком CSS-окружении. Чёрное боди с синим креслом сохранено как запасной вариант с `srcset` 640/960/1600 px; переключатель — `activeHeroPortrait` в `src/data/home.ts`. Пропорции исходников сохранены, генеративная ретушь не применялась.
- `HomeSections` собирает новую главную; `StoryCard` используется на главной, в архиве и на странице услуги.
- `StoryVideo` сохраняет нативные controls и добавляет крупную доступную кнопку «Смотреть», постеры, необязательные WebVTT и краткое содержание. `initStoryMedia` подключается через `mountApp`.
- Сохранены keyboard-навигация, skip-link, focus states, мобильное меню, FAQ и `prefers-reduced-motion`.

## Стек

Vite 7, Tailwind CSS 4, TypeScript, `@fontsource-variable/manrope`. React и другие UI runtime не подключены. Шрифты и медиа размещаются локально; внешнего font-сервиса нет.

## Что остаётся прототипом

- Формы и `NoopQuizSubmissionAdapter` не отправляют и не сохраняют данные.
- Вопросы, scoring и четыре результата теста демонстрационные. В этой итерации изменено название теста, а не его алгоритм.
- Контакты, реквизиты, юридические документы, цена и параметры сопровождения требуют утверждения.
- Блог пока состоит из коротких демонстрационных материалов.
- Стикеры на фото и видео Веры сохранены в самих файлах. Окончательный объём использования чувствительных материалов требует согласования с героиней и её представителем; закрытие лица этого не заменяет.
- Автосубтитры Даши требуют финальной проверки на слух; один неуверенно распознанный фрагмент явно обозначен.
- CMS, редактор контента WordPress и рабочий backend не реализованы этим редизайном.
- `noindex` сохранён. Локальная сборка не означает публикацию новой версии.

## Архитектура теста

`src/quiz` содержит типы, reducer, validation, scoring и controller. UI-компоненты в `src/components/quiz` отображают состояние. Adapter возвращает локальный статус `not-sent`, без сети, browser storage и логирования контакта.

Payload adapter-а не содержит сырые ответы: только контакт, result key, whitelist UTM, landing path и consent timestamp. После показа результата контакт удаляется из состояния вкладки.

Клавиатура: Tab / Shift+Tab, стрелки и Space в radio group, Enter для следующего шага, цифры 1–4 при фокусе на заголовке вопроса. «Назад» сохраняет ответы.
