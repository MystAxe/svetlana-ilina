# Светлана Ильина — браузерный прототип

Автономный многостраничный сайт на Vite и TypeScript: главная, «Формула тела», тест, блог и раздел «Истории перемен». Production-сборка полностью статическая и публикуется без PHP, базы данных и WordPress. В репозитории есть только сборочный адаптер для копирования frontend-артефактов в заранее подготовленную внешнюю WordPress-тему; редактирование контента из админки пока не реализовано.

## Запуск

Требуется Node.js 22.12+ или 24+.

```bash
npm.cmd install
npm.cmd run dev
```

Маршруты:

- `/` — новая editorial-главная;
- `/formula-tela/` — существующий структурный прототип услуги;
- `/test/` — существующий интерактивный тест.
- `/istorii-peremen/` — архив историй с фильтром по узнаваемым ситуациям;
- `/istorii-peremen/polina/` — полная история Полины из 12 смысловых экранов.
- `/istorii-peremen/sveta/` — история Светы из 12 смысловых экранов;
- `/istorii-peremen/vika/` — история Вики из 13 смысловых экранов; неподтверждённые медиа обозначены честными заглушками.
- `/istorii-peremen/oksana/` — история Оксаны после родов с голосовым сообщением и 13 смысловыми экранами; фотографии и видео ожидаются.
- `/nastavnichestvo/`, `/o-svetlane/`, `/contacts/` — самостоятельные содержательные страницы;
- `/blog/` и три вложенные статьи — рабочий блог-каркас без медицинских обещаний;
- `/thank-you/` — состояние после будущей отправки формы;
- `/privacy-policy/`, `/personal-data-consent/`, `/offer/`, `/requisites/` — существующие маршруты с явным статусом юридического черновика.

Проверка типов и независимая статическая production-сборка:

```bash
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```

Готовый сайт находится в `dist/client`. Настройки для обычного хостинга описаны в [руководстве по публикации](docs/DEPLOYMENT.md).

В PowerShell используется `npm.cmd`, поскольку локальная execution policy может блокировать wrapper `npm.ps1`. В других shell подходит обычный `npm`.

## Стек и зависимости

- Vite — dev-сервер и multi-page production-сборка.
- Tailwind CSS 4 + официальный Vite-плагин — utility CSS и semantic brand tokens.
- TypeScript — типы контента, состояния теста и adapter-контракта.
- `@fontsource-variable/manrope` — локальная доставка Manrope без запросов к внешним font-сервисам. Source Serif 4 подключен локальным variable WOFF2 и используется только для крупной display-типографики. Обе гарнитуры распространяются по SIL Open Font License 1.1; лицензия Source Serif 4 лежит рядом с font-файлом в `public`.

UI runtime и JavaScript-фреймворков нет. React, Bootstrap, Elementor, Flowbite и Preline не подключены. Иконки не требуют отдельной зависимости.

## Визуальная система этой итерации

- Canvas `#FFFFFF`, основной текст `#111111`, сильный текст `#090909`.
- Акцент `#C1121F`, hover `#A90F18`, мягкий фон `#FFF4F3`.
- Source Serif 4 используется только для H1/H2, главных цитат и крупных смысловых метрик; Manrope — для текста, интерфейса, фактов, малых номеров и вторичных заголовков.
- Запрещенные Tailwind-палитры, синий prototype-акцент, gradients, glassmorphism, тяжелые shadows и UI-kit cards не используются.
- Локальные SVG placeholders честно подписаны. `EditorialPicture` уже принимает AVIF/WebP `srcset`, fallback, `sizes`, размеры и crop; реальные изображения пока не подставлены.
- Motion построен на шкале 180/220/260 мс: логические группы текста, действий, медиа и карточек раскрываются коротким каскадом, а не целыми секциями; также сохранены мягкие состояния контролов, выезжающее мобильное меню, переходы теста и progressive cross-document View Transitions. `src/lib/motion.ts` включает эффекты только после готовности DOM; при `prefers-reduced-motion` контент показывается сразу без декоративного движения.

## Границы работы

- `/formula-tela/` и `/test/` не редизайнились: на них распространились только глобальные brand tokens, шрифты, header и footer.
- Quiz reducer, scoring, validation, mock-data и adapter-контракт не менялись.
- `NoopQuizSubmissionAdapter` ничего не отправляет и не сохраняет; REST-отправка теста отсутствует.
- Подтверждённые фото и видео подключены к историям Полины, Светы и Вики; голосовое сообщение Оксаны опубликовано в OGG и MP3, а ожидаемые фотографии и видео обозначены нейтральными заглушками без вымышленного содержимого.
- Публичное название — «Истории перемен». Сейчас истории и остальные тексты хранятся в структурированных TypeScript-данных, а не в базе WordPress.
- PHP-тема, CPT, поля редактора и импорт текущего контента не входят в этот репозиторий. Их нужно реализовать перед переносом, чтобы страницы, истории, медиа и SEO-поля действительно редактировались из админки.
- Публичный frontend не зависит от WordPress и может размещаться на любом статическом хостинге.

## Архитектура теста

`src/quiz` содержит типы, reducer, validation, scoring и controller. UI-компоненты в `src/components/quiz` только отображают состояние. `QuizSubmissionAdapter` описывает будущий транспорт, а `NoopQuizSubmissionAdapter` возвращает локальный статус `not-sent` без сети, хранилища и логирования.

Payload adapter-а конструктивно не содержит сырые ответы: только контакт, result key, whitelist UTM, landing path и consent timestamp. После показа результата контакт удаляется из состояния вкладки.

Клавиатура теста:

- `Tab` / `Shift+Tab` — переход между элементами;
- стрелки и `Space` — нативная работа radio group;
- `Enter` — следующий шаг;
- цифры `1–4` — выбор варианта, когда фокус находится на заголовке вопроса;
- «Назад» сохраняет выбранные ответы.
