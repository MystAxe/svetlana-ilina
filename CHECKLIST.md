# Проверка сайта

## Промежуточная проверка

- [x] На главной есть три товара с ценами и маршрутами из сентябрьских ТЗ.
- [x] Страницы «СЫТАЯ», «Формула тела» и наставничества содержат согласованные в ТЗ форматы и цены.
- [x] На мобильной ширине проверены блок товаров и первые экраны трёх страниц.
- [x] В закрытой программе собраны тест ДО, дни 1–7, сравнение и финальная карта; видео №1–3 привязаны к первым трём дням.
- [x] Видео лежат вне публичного каталога, а WordPress-маршрут проверяет доступ перед выдачей файла.
- [ ] Проверить весь курс с авторизованным тестовым пользователем в работающем WordPress.
- [ ] Получить и согласовать четыре визуала тарелок и тексты видео для раскрывающихся блоков.

- [x] Все 10 вопросов отображаются в правильном порядке.
- [x] Без ответа нельзя перейти дальше; кнопка «Назад» сохраняет выбор.
- [x] Пять контрольных сценариев приводят к ожидаемым результатам.
- [x] Сопутствующий результат появляется только при близких баллах.
- [x] Результат показывается без регистрации и отправки данных.
- [x] Ссылки на пять историй и «Формулу тела» открывают существующие маршруты.
- [x] Клавиатура, фокус, прогресс и сообщения об ошибке доступны.
- [x] На 320, 390, 768, 1024 и 1440 px нет наложений и горизонтальной прокрутки.
